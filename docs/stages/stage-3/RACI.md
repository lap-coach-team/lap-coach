# RACI-матриця

## Легенда

- **R (Responsible)** — виконує роботу
- **A (Accountable)** — відповідає за результат і приймає його; рівно одна на рядок
- **C (Consulted)** — з ним радяться до та під час роботи
- **I (Informed)** — отримує інформацію про результат
- **A/R** — одна людина і виконує, і відповідає (рахується як R)
